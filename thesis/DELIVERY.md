## 研究证据与主要结论

工作1保持已发表内容，工作2独立重建。新研究包括四类控制器各三个优化初始化、512次共同结构验证、1152次泛化开发、实际更新幅度校准、特征移除和60次单进程计时。

最终测试使用十种冻结方法、四个环境条件，每项30个独立环境种子，全部固定运行100000步，共1200次，无结果排除。完整模型相对已调固定合作规则的全程合作优势为4.105–5.255个百分点；学习评分相对固定评分门控的增量较小且随条件改变。方法依赖合作语义，不能将高合作直接解释为普遍识别消息真伪。

关键结果见第五章及`final-report.json`。原图没有逐次数据时不补造区间；训练输出与环境重复分开计数。单次快照预先选择1000号种子，不按结果挑选。

## 在解压目录复现

先核对原始归档：

```bash
sha256sum -c MANIFEST.sha256
```

安装实验依赖：

```bash
python3 -m venv .venv-thesis
.venv-thesis/bin/python -m pip install -r work2/requirements.lock.txt
```

完整重放主方法的一次受扰测试：

```bash
.venv-thesis/bin/python work2/replay_run.py work2/results/final-test-20260915 --run 90 --out replay-final-run90
```

该配置为L=30、r=4.8、10%持续高奖励背叛、种子1000、100000步。交付前在本机从归档引擎重放，Q表、动作、异常掩码、分段轨迹及全程/末段统计均精确一致。跨硬件或依赖变化后的浮点一致性仍以实际比较为准。这个重放是复现检查，不新增统计样本。

最终统计可使用归档分析程序重算；请在工作副本中运行，以保留交付归档原样：

```bash
.venv-thesis/bin/python work2/results/final-test-20260915/source/summarize_final_test.py work2/results/final-test-20260915
```

部分开发记录中的复用来源为原机器绝对路径。单条重放与最终测试汇总不依赖这些旧绝对路径；跨开发批次的旧汇总程序需要按REPRODUCE.md重定位工作副本中的来源。原始清单不改写。
