## 2. 数学与口径静态核验

### 2.1 空间公共物品博弈福利恒等式

在周期格点、每个个体参与五个五人组、每组合作成本为1的设定下，组内总真实收益为

`(r - 1) * n_C`。

每个合作者被五个组计数，因此全系统满足

`sum_i P_i = 5 * (r - 1) * N_C`，

从而

`mean(P_i) = 5 * (r - 1) * f_C`。

该关系与第二章福利定义、第四章训练目标及第五章“标准化福利等于合作率”的解释一致。

### 2.2 工作1即时综合奖励差

固定其他节点动作，一个节点由背叛改为合作时，五个重叠博弈组中的累计原始收益变化为`r - 5`。采用工作1归一化后，正文给出的

`R(C)-R(D) = w_P (r-5)/(3r+5) + (1-w_P)`

成立。合作即时综合奖励不低于背叛的阈值

`w_P <= (3r+5)/(2r+10)`

也与正文一致；`r=3`时阈值为`0.875`。

### 2.3 消息暴露概率

固定从`N=900`个节点中无放回选择`K=90`个异常发送者，接收者有`d`个候选邻居时，至少一个候选异常的概率为

`1 - C(N-d,K)/C(N,K)`。

直接计算得到：

- `d=4`：约`0.344387`；
- `d=12`：约`0.719883`。

与第四章报告的约`0.3444`和`0.7199`一致。

### 2.4 单步NI界与Q值范围

第四章中局部归一化满足`A_i <= D_i`，且门控`0 <= g_i <= 1`，所以

`|Delta Q_i| <= kappa_max * g_i <= kappa_max`。

在`R in [0,1]`、`0 < eta <= 1`、`0 <= gamma < 1`下，正文给出的保守Q值区间

`L_Q <= -kappa_max/[eta(1-gamma)]`

和

`U_Q >= (eta+kappa_max)/[eta(1-gamma)]`

可由一步更新归纳得到。代入`eta=0.8`、`gamma=0.9`、`kappa_max=0.5`得到`[-6.25,16.25]`，与正文一致。

### 2.5 Bonferroni区间口径

八项主要比较控制总alpha为`0.05`时，逐比较置信水平为

`1 - 0.05/8 = 0.99375`，

即`99.375%`。当前最终测试章节明确写出：每个条件先形成30个环境种子的配对差，再以这30个配对差为bootstrap重采样单位；节点和时间步不作为独立重复。
