# 显式合作指示量的冻结参数消融

本补充落实RESEARCH_PLAN.md中已经列明的动作特征消融。制定时最终留出测试尚未启动，现有控制器与主要测试分析已冻结。本实验不重新选型或更改最终测试比较。

首轮10参数模型与12参数修订模型同时改变了特征和初始化，不能把前后差值当作单一合作语义特征的贡献。这里直接在最终完整模型3100-last_generation_best上，将报告合作指示量对应的评分权重w5与门控权重v5置零，即程序索引4和9，其余参数不变，不重新训练。

环境沿用特征检查：L=30、M=2、声誉状态、r∈{4.4,4.8}、干净/10%持续高奖励背叛、种子212–215、固定100000步。新增16次，复用共同结构验证的完整模型16次。记录全程和末段合作、实际NI幅度与逐种子配对差。全部运行保留，不用节点或时间步扩充重复数。

这个对照只删除显式的合作指示量；动作一致性、按报告动作索引的自身经验残差以及NI自身的动作一致性符号仍保留。因此不称为移除全部动作信息，也不称为不使用社会信息。运行仍计算全部特征，不用于证明计算节省。

结果用于描述已训练参数对这一显式语义输入的依赖，不能代表去掉该特征并重新训练后的最优表现。该批与正式测试分别记录，无论结果如何，均不据此修改冻结控制器。
