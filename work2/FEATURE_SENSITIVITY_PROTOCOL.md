# 训练后特征移除敏感性协议

2026-09-15，在本批运行前确定。目的为检查已训练完整控制器对自身经验残差和Q值接近量的依赖，补充结构重训实验。**本批不重新训练**，不能把结果解释为删除特征后重新优化可达到的能力上限，也不把性能差单独归因为真假识别。

固定结构验证选中的完整模型3100-last_generation_best，其余参数和仿真定义不变：

1. 无经验残差：评分与门控的残差系数theta[3]、theta[8]置零。
2. 无Q值接近量：theta[10]置零。
3. 两者均移除：theta[3]、theta[8]、theta[10]置零。

这使对应特征不再影响评分或门控；执行器仍可计算这些量，因此本实验不用于计算开销比较。

采用结构验证已用的212–215号种子，L=30、M=2、声誉状态、r∈{4.4,4.8}、干净与10% high_defect、100000步与末20%窗口。三个变体新增48次仿真，原完整模型的16次结果直接引用validation-structure-20260915，不重新计为独立样本。旧引擎与当前引擎的76组精确回归已通过；不同批次各自保留源码。

报告三种移除相对完整模型的逐条件全程和末段配对差、全部四次值及范围。同时查看实际NI幅度，以避免将更新幅度变化忽略不计。结果只说明冻结参数在移除输入后的敏感性；残余参数未重新适配，特征间可能存在交互，不宣称可相加的独立信息贡献。

不依据本批合作率改选控制器，不使用最终测试种子。来源、移除位置及全部输出归档。工具来源沿用RESEARCH_PLAN.md记录的实验设计与统计分析技能。
