# 可训练候选方法的具体定义

本文件定义已实现、正在开发检验的候选方法；是否有效仍需独立验证，不能依据模型定义宣称实验成功。选择“局部信息选择与修正控制”作为描述性名称，暂不创造新的英文缩写。已实现基线见engine.py；当前候选虽也存储12个参数，但与原汇报模型不是同一个实现。首轮10参数定义和结果见results/cem-20260915/source/MODEL_SPEC.md及独立验证档案。

## 接收端可用信息与特征

每轮在自身TD更新完成后、附加NI更新之前，接收者i可用：本轮真实动作a_i和真实综合奖励R_i；当轮收到的邻居报告(a_hat_j,R_hat_j)；自身Q表；截至上一轮的自身分动作奖励预测均值mu_i(C),mu_i(D)。不可用：异常身份、邻居未篡改的真实值、未来收益、邻居Q表。

对每个候选j计算五个特征：

1. 奖励优势：x1=R_hat_j-R_i。
2. 动作一致性：x2=+1（a_hat_j=a_i），否则-1。
3. 横向差异：x3=abs(R_hat_j-median_k R_hat_k)。
4. 自身经验残差：x4=abs(R_hat_j-mu_i(a_hat_j))。
5. 合作报告指示：x5=1（报告C），否则0。该项使共享线性评分能够表达固定合作优先，不能将它单独称为可信度特征。

所有奖励限定在预实验的合法归一化区间[0,1]内。median对12个候选取中间两个值的平均。x3/x4是异常线索，不是真假标签：真实高收益同样可能偏离中位数，本地不同空间条件也可能使邻居表现偏离自身历史。

mu初值0.5，依据自己真实经验，在本轮NI完成后仅更新实际执行动作对应项：mu_i(a_i)←0.95*mu_i(a_i)+0.05*R_i。不能把本轮尚未使用的未来信息提前加入；残差只作辅助，未经动作取样充分性核验不称为校准预测误差。

## 选择与连续强度

评分z_ij=w^T x_ij，w为5个共享参数。选取z最高的邻居，精确并列时使用预先抽取的固定随机数均匀处理。不给评分器添加公共偏置，因为它不改变排序。

u_i=1/(1+abs(Q_i(s_i,C)-Q_i(s_i,D)))作为个体价值接近程度的代理量。它不是真实置信度或概率。

门控g_i=sigmoid(b+v^T x_i,j* + v_u*u_i)，其中v含5个参数，再加v_u和b。共享可训练参数共12个。门控是连续幅度，不是消息使用概率。

保持正奖励优势条件和动作一致性修正：

ΔQ_i = κ_max * g_i * max(0,R_hat_j*-R_i) / (max_k abs(R_hat_k-R_i)+0.01) * sign(a_i=a_hat_j*)。

κ_max先使用0.5，与局部NI基线保持同最大强度；是否调整在开发集决定。所有数据来自局部接收端，不再使用全局奖励差。标准TD项不变，选中的消息不直接输出行为动作。

## 必要对照与可证伪性

- 同局部归一化的最佳邻居、不同固定κ；避免将归一化变化当作控制器增益。
- 已实现上尾过滤，以及优先合作消息：检验复杂方法是否只是过滤或合作偏置。
- 固定评分+仅学习门控，学习评分+固定门控，完整学习；消融每个特征时重新训练并固定相同预算，同时另做执行时去除以区分训练适应。
- 将完整模型的平均实际绝对修正强度与固定κ基线匹配，仅在开发集估计匹配参数。
- 如果任一简单规则在多个条件下达到同等表现且开销更低，应将其作为主要方法候选，不能只保留复杂控制器。
- 条件至少覆盖干净、高奖励+背叛、仅高奖励、仅动作错误。扩展攻击在开发阶段先确定，正式未见攻击需预留。

## 优化与训练数据

采用交叉熵方法（CEM）对12维参数进行黑盒优化：高斯候选分布、按预定目标选取前20%候选、更新均值/标准差并保留方差下限。当前预算24候选×12代，独立优化初始化3个；参数在运行前写入配置并归档。

候选评价运行完整的在线Q学习。每次训练仿真10000步，随后在100000步验证窗口上选型并检验时长迁移，不能默认短时训练等于长期最优。

训练域先覆盖r=4.4和4.8的干净/10%高奖励背叛四单元。每代使用共同环境种子比较候选，代际从训练种子池切换；为降低固定种子过拟合，最终用独立验证种子选择模型。训练目标为各单元等权的全程平均标准化真实福利：mean_t [P_bar(t)/(5(r-1))]。在本环境它严格等于全程平均合作率，明确承认该等价关系。优化完整轨迹不等于对仿真端到端反向传播。

只有冻结模型/超参数后才访问正式测试种子1000–1029。优化初始化作为更高层重复，评估每个冻结控制器在相同测试环境种子上的差异；不要把多个控制器×同一环境种子当作相互独立的大样本。

## 可以给出的有限性质

在规定的合法消息区间和正则化下，单步附加修正满足abs(ΔQ_i)≤κ_max*g_i≤κ_max。g=0或κ_max=0时，在同随机流下精确退化为IQL。这个单步界不等于对多轮不同策略轨迹的拜占庭鲁棒保证，也不保证局部选择一定是真实邻居。

## 首轮10参数开发记录（2026-09-15）

根据30×30网格中2000步的接收端控制器成本测量，首轮实际使用24候选×12代，每次候选评价10000步，每代一个训练环境种子、四个r/异常单元。三个优化初始化为3000、3001、3002；环境种子从110–199抽取，未使用验证或测试集。共有3456个训练仿真。首轮3456次训练仿真均已完成，耗时约1091.8秒；这仍是开发训练，不能用其得分证明独立环境表现。每次优化的最终均值与末代最佳参数一并输出，之后在独立验证集比较；不以跨代不同环境种子上的最高分直接选择唯一模型。

实际实现：engine.py中的local_controller只接受本地输入；gate_only固定最高奖励排序、训练门控，selection_only训练评分但门控固定1。cooperation_first在有合作报告时选择其中最高奖励，无合作报告时选择最高奖励，平局随机。gate_scale=0用于验证精确IQL退化。

## NI对动作价值差的等价表示

令d_i=Q_i(s_i,C)-Q_i(s_i,D)，h_i=κ_max*g_i*A_i/D_i≥0。NI项对d_i的改变量为：所选消息报告C时+h_i，报告D时−h_i，和接收者实际动作无关。这里只固定当前状态并分离出NI单项，不包含TD、后继状态变化或长期轨迹。

因此，门控调整强度，参考动作决定这项修正对合作偏好的方向；门控不能直接反转背叛报告的影响。这也说明简单合作消息优先是必要的对照，高合作率不等价于消息真假识别。

## 第二轮表示能力核验（2026-09-15）

首轮独立验证中简单合作优先在四个条件上均优于学习模型。当前增加x5合作报告指示，评分5参数、门控7参数，总计12参数；其他时序、奖励和局部信息边界保持不变。旧10参数源代码与数据已归档，不用当前默认参数数目重新解释旧运行。

新增cooperation_only对照：按合作优先选择；若所选消息报告D，将门控设为0，否则为1。其单步NI不会降低合作价值优势；若所有消息均报告D，则Q学习轨迹精确退化为IQL。该性质约束同一步附加更新，不能推广为长期合作率单调或任意消息攻击鲁棒。

表示核验：12参数评分取w=(1,0,0,0,2)，门控固定1时，在既定报告奖励区间内能够表达合作优先排序，200步契约检查中Q表与全部记录指标逐项相同。新增方向约束与全D消息检查通过，现共有15项契约检查。

方向/强度开发批次固定种子104–107，四种r/异常单元，每次100000步；比较合作优先和合作方向限制的κ∈{0.05,0.1,0.2,0.5}，另含IQL、全局NI、上尾过滤和未训练的语义初始化，共192次。先检查是否仅调固定强度就能解释改进。

方向/强度开发已经完成：κ=0.2时合作优先全程目标0.931103，合作方向限制0.931131；κ=0.5合作优先为0.911986。第二轮CEM因此从w=(1,0,0,0,2)、固定门控0.4初始化（偏置ln(2/3)，其余门控参数0），在κ_max=0.5下对应实际固定强度0.2。三个优化初始化3100、3101、3102；24×12代、四单元10000步，来源和配置在训练前冻结。仅评分消融将门控固定0.4，完整及仅门控模型可学习门控；所有配置必须随候选文件记录。最终方法仍需由对照证据决定。

## 消息类型与状态敏感性扩展

`GENERALIZATION_PROTOCOL.md`固定了八类消息条件及声誉/自身上一动作两种状态。新增消息只修改NI接收内容，不修改真实博弈动作、收益或声誉状态；`own_action`以D初始化，下一状态为本轮实际动作，保持2×2 Q表。随机消息使用独立第四随机子流，不影响既有三个子流。当前19项契约检查通过，76组旧引擎输出精确回归通过；归档旧批次继续以其自身源码快照为准。
